# Instinct Algo Version History

## Current Version: V1.1

**Release Date:** February 27, 2024

### Key Features

- ML Ensemble strategy with Random Forest, Gradient Boosting, and Logistic Regression
- Realistic backtesting with transaction costs and slippage
- Advanced risk management with adaptive position sizing and stop losses
- Signal smoothing and filtering to reduce false signals
- Comprehensive performance metrics and analysis
- Multi-exchange data loading from Binance, Coinbase, and Kraken
- GPU acceleration capabilities (where hardware is available)

### Major Improvements from V1.0

- Complete rewrite of backtesting system for realism
- Addition of proper risk management with volatility-based position sizing
- Implementation of transaction costs and slippage modeling
- Addition of drawdown-based stop loss mechanisms
- Signal smoothing to prevent excessive trading
- Comprehensive documentation
